< Formatação de textes

Principais formatações

Negrito / Destaque

Nesta frase temos um texto em negrito usando a tag <b> (não semântica)

Nessa frase temos um texto em negrito usando a tag <strong>

Itálico / Enfase

Nesta frase temos um texto em itálico usando a tag <i> (não semântica)

Nessa frase temos um texto em itálico usando a tag <em>

Texto marcado

Podemos criar um texto marcado usando a tag <mark>

E no outro parágrafo temos outro texto marcado no final. /p>

Texto grande e pequeno

Podemos criar um texto grande usando a tag <big>

Podemos criar um texto pequeno usando a tag <small>

Texto deletado

Podemos criar um texto deletado usando a tag <del>

Texto inserido

Podemos criar um texto inserido usando a tag <ins>

Texto subscrito e sobrescrito

Podemos criar um texto subscrito usando a tag <sub>

Podemos criar um texto sobrescrito usando a tag <sup>
